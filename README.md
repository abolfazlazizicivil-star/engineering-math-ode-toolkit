# Engineering Mathematics & ODE Toolkit

A Python toolkit for engineering mathematics, numerical methods, and differential equations.

## Features

- Euler and classical RK4 methods for first-order ODEs
- Vector ODE systems
- Second-order ODEs
- Mass-spring-damper engineering example
- Numerical root finding
- Numerical integration
- Numerical differentiation
- Tests, examples, documentation, and GitHub Actions CI

See the project documentation and examples for usage.
